# DFW Retail & Demographic Explorer

A GIS-based exploratory project examining retail locations and demographic patterns across the Dallas–Fort Worth urban area.

## Purpose

This project is being developed as a proof of concept for exploring how GIS could support retail, sustainability, and consumer-market analysis.

## Current data

- USDA SNAP retailer locations
- U.S. Census urban areas
- Census tract and block group geography
- ACS demographic data

## Project structure

- `data/raw/` — original source data
- `data/interim/` — temporary processing outputs
- `data/processed/` — cleaned and analysis-ready datasets
- `gis/` — ArcGIS Pro project and GIS-specific files
- `docs/` — methodology and data documentation
- `outputs/` — maps, figures, and exported results
- `assets/` — logos and other design assets
- `scripts/` — reproducible processing/analysis code
